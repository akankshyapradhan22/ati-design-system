# Components

90+ production-ready components built on **React Aria** for accessibility, styled with **Tailwind CSS v4**.

## Base Components

The core building blocks found in `apps/web/src/components/base/`.

| Component | Path | Description |
|---|---|---|
| [Button](button.md) | `base/buttons/button` | All button variants with icons, loading, destructive |
| [Badge](badge.md) | `base/badges/badges` | Status labels with dot and icon variants |
| [Avatar](avatar.md) | `base/avatar/avatar` | User images with status, initials, and label groups |
| [Input](input.md) | `base/input/input` | Text fields with icons, validation, groups |
| [Checkbox](checkbox.md) | `base/checkbox/checkbox` | Checkboxes with indeterminate state |
| [Toggle](toggle.md) | `base/toggle/toggle` | On/off switches |
| [Select](select.md) | `base/select/select` | Dropdown and ComboBox with search |
| [Tooltip](tooltip.md) | `base/tooltip/tooltip` | Contextual hover hints |
| [Tabs](tabs.md) | `base/tabs/tabs` | Horizontal tab navigation |
| [Pagination](pagination.md) | `base/pagination/pagination` | Page navigation controls |
| [Slider](slider.md) | `base/slider/slider` | Range and single-value sliders |
| [Button Group](button-group.md) | `base/button-group/button-group` | Segmented control |
| Radio Buttons | `base/radio-buttons/` | Radio groups |
| Tags | `base/tags/` | Dismissible tag chips |
| Textarea | `base/textarea/` | Multi-line text input |
| Form | `base/form/` | Form layout + validation |
| Dropdown | `base/dropdown/` | Contextual menu |

## Application Components

Complex patterns in `apps/web/src/components/application/`.

Includes: Date Picker, Modal, Table, Stepper, File Upload, Notification, Sidebar Navigation, and more.

## Marketing Components
