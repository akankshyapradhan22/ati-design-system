# Loading Indicator

Spinner and loading state indicators.

**Import**

```tsx
import { LoadingIndicator } from "@/components/base/progress-indicators/loading-indicator";
```

## Usage

```tsx
<LoadingIndicator size="sm" />
<LoadingIndicator size="md" />
<LoadingIndicator size="lg" color="brand" />
<LoadingIndicator size="xl" color="gray" />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `sm \| md \| lg \| xl` | `md` | Spinner size |
| `color` | `brand \| gray \| white` | `brand` | Spinner color |
