# Spacing & Border Radius

## Spacing

The design system uses a 4px base unit. Tailwind's default spacing scale applies: `p-1` = 4px, `p-2` = 8px, etc.

| Tailwind | px | rem |
|---|---|---|
| `1` | 4px | 0.25rem |
| `2` | 8px | 0.5rem |
| `3` | 12px | 0.75rem |
| `4` | 16px | 1rem |
| `5` | 20px | 1.25rem |
| `6` | 24px | 1.5rem |
| `8` | 32px | 2rem |
| `10` | 40px | 2.5rem |
| `12` | 48px | 3rem |
| `16` | 64px | 4rem |
| `20` | 80px | 5rem |
| `24` | 96px | 6rem |

## Border Radius

| Token | Value | Usage |
|---|---|---|
| `--radius-none` | 0px | No rounding |
| `--radius-xs` | 2px | Tags, tiny badges |
| `--radius-sm` | 4px | Checkboxes, small pills |
| `--radius-md` | 6px | Inputs, dropdowns |
| `--radius-lg` | 8px | Cards, buttons (default) |
| `--radius-xl` | 12px | Modals, larger cards |
| `--radius-2xl` | 16px | Panels |
| `--radius-3xl` | 24px | Large containers |
| `--radius-full` | 9999px | Pills, avatars, toggle knobs |

## Max Width

| Token | Value | Usage |
|---|---|---|
| `--max-width-container` | 1280px | Page layout container |
